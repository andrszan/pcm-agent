# 测试编写

- 测试真实行为、稳定协议和回归风险，不为凑数量写测试，也不因测试简单就删除。
- 不逐句校验 prompt、注释或说明文案，不用源码关键词或导入名称代替行为验证。字符串断言只用于协议、输入保真、脱敏等确需精确比较的场景。
- Prompt 测试检查资料传递和调用接线，不复制提示词内容。Mock 预设的结果不能证明模型的判断能力。
- 优先删除混合测试中的无效断言，保留有效保障；修改后运行相关回归，不为通过测试而放宽断言。
