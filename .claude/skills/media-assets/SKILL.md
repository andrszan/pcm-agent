# media-assets — 开发期媒体资源

## 定位

这是一个可独立调用的开发期媒体资源能力。它根据当前产品与工程事实判断媒体是否有明确价值，选择已准入且能力匹配的 Provider，受控地取得有限候选，并将最终采用的资源固化到调用方项目的实际资产位置。

本能力可以在适用任务中由 Agent 按需调用，但不因为能力存在就机械添加图片或视频。媒体应改善内容识别、品牌表达、数据理解、真实上传验证或用户决策；没有明确价值时不为装饰而引入无关素材。

本能力不负责产品运行时媒体搜索、对象存储架构、数据库设计、权限、迁移、恢复或批量内容生产，也不把任何 Provider 变成目标产品的隐藏依赖。

## 核心合同

开始实际获取前，先从当前可访问事实收敛：

1. 资源的用户价值、页面或测试用途；
2. 类型、主题、构图、比例、风格、文字限制和禁止元素；
3. 目标项目已有的资产约定与最终落点；
4. 需要候选、下载、生成还是复用 fixture；
5. 当前任务是否已经授权相应的外部调用和文件写入。

当前开发任务已经明确要求创建并落地相应媒体，且目标位置能由工程事实安全确定时，可以继续执行；只需方向建议、目标位置不明、外部调用可能产生未授权成本或存在多个实质不同方案时，只形成有限候选或请求必要决定。

## Provider 选择

Provider 是本能力内部的可选适配，不是其它 Skill、Plugin 或产品模块。先读取 `providers/README.md` 中受维护的 Provider catalog；不得扫描任意目录、自动注册新文件、安装依赖或把未登记来源视为可用 Provider。

- 调用方明确 Provider 时，只读取 catalog 映射的对应说明，核验状态、能力、配置和限制；
- 来源未明确时，按媒体用途和所需能力筛选已准入 Provider。只有一个明显匹配项时直接采用；多个同等可行项涉及不同成本、来源权利或结果语义时，只比较少量候选并请求决定；
- 没有匹配项、配置缺失、服务不可用、接口不兼容、额度不足或使用边界不满足时，报告真实缺口；
- 已选择的 Provider 失败后不静默改用另一个来源，也不自动安装 SDK、CLI、Plugin 或连接未声明的公共服务。

Provider 凭据只从调用方授权的受保护配置取得。不得回显、复制到目标产品配置、写入业务数据、测试清单、日志或最终回复。

## 候选检查与资产固化

无论使用哪种 Provider，都遵循以下规则：

1. 每次围绕一个明确目标取得有限候选，不自动扩展关键词、翻页抓取、并发预热、循环生成或建立素材库；
2. 结合视觉内容、OCR、主体语义、构图、比例、异常文字、水印、品牌标识、敏感内容和目标容器适配性检查候选；
3. 只处理最终选定的少量资源，不用检索或生成结果批量填充数据库、Seed、列表、索引或用户内容；
4. 临时预览、下载或签名 URL 只用于当次处理，不能成为页面、数据库、Seed、fixture 或其它产品运行时依赖；
5. 将选定资源写入目标项目已有约定的位置，并按用途核验真实 MIME、文件特征、尺寸或时长、体积、完整性与可读性；必要时记录哈希；
6. 产品 UI 默认不展示每张已固化静态资源的来源。只有调用方存在明确许可、合同、审计、替换或产品展示要求时，才保留相称的最小内部依据。

生成式 Provider 的输出还应检查可维护性。模型图片中的文字不作为最终 Logo 或品牌名称；文字标识应由 SVG、字体或其它可编辑机制承载。不得无上限重复生成，也不得将生成能力用于普通业务数据的批量配图。

## Fixture 维护与使用

本 Skill 随附的 `assets/fixtures/` 保存稳定测试输入及维护说明。真实 fixture 由维护者按需添加，本能力不为填满目录而自动下载或生成测试资源。

- Fixture 用于上传、预览、格式、大小和失败状态等测试，不是产品静态资产、公开素材库或对象存储模拟器；
- 测试优先复用稳定 fixture，并复制到目标项目约定的测试位置，不在每次测试时联网随机获取；
- 产品专属视觉资源进入目标项目自己的资产位置，动态用户媒体由对应产品设计和开发处理；
- 添加、替换或删除 fixture 时遵循随附维护说明，不保存秘密、完整 Provider 响应或临时 URL；
- 涉及上传时使用目标项目真实上传路径验证，不能以 Mock、文件存在或截图代替真实行为。

## 停止边界

遇到以下情况时停止直接执行并报告影响：

- 需要决定产品是否将媒体作为核心输入、输出或必需内容；
- 需要创建对象存储、修改数据库、设计权限、清理、迁移或恢复；
- 计划系统性批量搜集或生成业务媒体；
- 目标位置、写入范围、成本或来源权利无法安全判断；
- 现有 Provider 不能满足已确定能力合同。

## 完成与汇报

完成后报告资源用途、Provider 选择依据摘要、候选检查结果、最终文件路径、文件校验、目标项目实际引用或测试结果，以及尚未解决的缺口。不得回显凭据、认证头、临时 URL、完整原始响应或敏感提示词。

不自动提交、建分支、合并或 push。
