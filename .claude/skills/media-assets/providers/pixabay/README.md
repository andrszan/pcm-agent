# Pixabay Provider

## 身份与能力

- **ID**：`pixabay`
- **状态**：`available`
- **能力**：搜索已有图片或视频候选；下载最终选定资源
- **适用**：官网与 UI 的通用摄影素材、Banner/封面、非敏感城市/自然/办公/科技示意图，以及有明确用途的少量短视频素材
- **不适用**：产品运行时搜索、数据库或 Seed 批量配图、素材库预抓取、需要独家或高度定制构图的品牌视觉

该 Provider 只负责开发期素材搜索和下载，不是存储层、CDN、产品模块或业务数据源。

## 官方参考

- [Pixabay API Documentation](https://pixabay.com/api/docs/)

实际调用前以官方文档中的当前 endpoint、参数、返回字段、缓存、限额和错误说明为准；本 adapter 负责补充本工作区的选择、固化与安全边界，不复制整份上游 API 文档。

## 配置合同

| 配置键 | 必要性 | 说明 |
|---|---|---|
| `PIXABAY_API_KEY` | 必需 | 开发期 API 凭据，只从调用方授权的受保护配置读取 |
| `PIXABAY_API_BASE_URL` | 可选 | 图片 API 基地址；未提供时使用当前官方图片 API 地址，视频接口按官方文档使用对应路径 |

不得把凭据写入请求日志、命令输出、目标产品配置、客户端、业务数据或清单。调用前核对当前官方 API 文档、限额与条款；本文不替代 Provider 的实时合同。

## 选择条件

在以下条件同时成立时选择：

1. 任务需要现有图库素材，而不是原创或严格定制构图；
2. 用途、主题、比例、目标位置和无图表现已经明确；
3. 当前任务允许进行开发期外部检索；
4. 选定资源将下载并固化，不会永久热链。

只需要视觉方向时可仅返回有限候选；实际下载前必须能确定最终候选和目标文件位置。

## 检索与候选归一化

- 每个视觉目标只使用一个明确查询，不自动扩词、并发查询或翻页；
- 首次只请求足够人工/Agent 比较的少量结果，通常为 3～10 个；
- 根据任务选择图片或视频接口，并开启适用的安全搜索条件；
- 将响应归一化为：Provider ID、资源 ID、媒体类型、预览、尺寸或时长、作者/贡献者、稳定资源页和当次临时下载信息；
- 临时下载地址只用于候选检查和当次下载，不写入最终产品、数据库、Seed 或 fixture 清单；
- 结合图像理解与 OCR 检查主体语义、构图、比例、文字、水印、商标、品牌和敏感内容。

不要保存整份 API 响应。需要维护来源依据时，只保留稳定资源 ID、资源页、贡献者和当前用途所需的最小许可说明。

## 下载限制

- 只下载最终采用的少量资源，通常每个视觉目标 1 个；确有对比或响应式变体需要时仍保持最小数量；
- 不遍历业务记录逐条搜索，不批量填充数据库、Seed、列表、索引或内容库；
- 不创建长期素材缓存或开放下载包；
- 受到限流时停止并报告，不通过并发、换 key 或扩大重试绕过；
- 网络、认证、限流、空结果、资源失效或下载失败时不自动改用其它 Provider。

## 许可与内容边界

使用前核对当前 Pixabay 条款、内容许可和资源页事实。通常允许使用不表示所有第三方权利已经自动清除：可识别人物、商标、包装、建筑、艺术作品和品牌场景仍需按实际用途判断。

产品 UI 默认不需要为每张已固化静态图片展示来源。只有当前条款、产品展示、合同、审计或替换要求需要时，才保留或展示相称信息。

## 落盘与验证

1. 下载到目标项目已有资产约定的位置，不保留临时 URL 作为引用；
2. 校验响应状态、真实 MIME、文件特征、扩展名、尺寸或时长、体积和可读性；
3. 使用目标项目实际构建、页面或数据路径验证资源可访问；
4. 必要时记录 SHA-256 和最小来源依据；
5. 发现内容错误、损坏、明显权利风险或不符合视觉目标时，放弃该候选并报告或在同一有限候选集中选择其它项。

不得因为某一候选失败而自动切换到生成 Provider。
