# 单张图片生成 Provider

- **ID**：`openai-compatible-image`
- **状态**：`available`
- **用途**：为开发任务生成少量原创静态图片；品牌背景、官网首屏或特定构图可直接采用，不必先穷尽图库。
- **边界**：只提供文生图，不提供图片编辑、提示词反推、批量配图或产品运行时服务。

## 固定执行方式

从工作区根目录执行已有脚本，不另写 API 程序、不调用其它创作流程：

```bash
uv run --no-project .claude/skills/media-assets/scripts/generate_image.py \
  -p "山地露营官网背景，赭红帐篷位于右侧且完整入画，四周保留裁剪空间，左侧暗部留白供浅色标题使用，自然晨光，无文字或 Logo。" \
  --size 1536x1024 -f frontend/public/images/camping-hero.png
```

示例输出目录不是强制约定，按目标项目实际资产位置设置 `-f`。已有文件不会被覆盖；需要替换时先生成到另一个明确路径，检查结果后再按项目授权更新引用。

| 参数 | 合同 |
|---|---|
| `-p` / `--prompt` | 已经收敛的视觉描述；与 `--prompt-file` 二选一 |
| `--prompt-file` | 可选的 UTF-8 长输入文件，不要求普通单图先写文件 |
| `-f` / `--file` | 必填，尚不存在的 `.png` 输出路径 |
| `--model` | 默认 `gpt-image-2`，只在当前服务已确认支持其它模型时显式指定 |
| `--size` | 默认 `1024x1024`，使用 `宽x高`，如 `1536x1024`；服务端具体尺寸限制以实际模型为准 |
| `--quality` | 默认 `medium`；支持 `low`、`medium`、`high`、`auto`，满足开发用途即可，不默认追求最高质量 |

每次固定 `n=1`、输出 PNG，不开放批量数量参数。脚本使用官方 OpenAI Python SDK 调用 Images API，支持 base64 或 HTTP(S) 图片 URL 返回；URL 仅用于当次下载，不保存为产品依赖。普通运行通过 `uv` 的 PEP 723 隔离环境准备脚本头固定的已验证依赖版本，不在目标前后端安装 Python 包；升级依赖时同步运行脚本回归与必要的真实接口验证。

## 配置

只使用 `OPENAI_BASE_URL` 和 `OPENAI_API_KEY`，两者均须非空。进程环境优先于**当前工作目录的 `.env`**，不向父目录搜索，不读取 `~/.env`，也不在配置缺失时静默使用另一个服务。基地址必须包含服务实际要求的 API 前缀，例如 `/v1`，但不包含 `/images/generations`；SDK 追加接口路径。

模型由脚本默认值或显式 `--model` 决定，不增加模型环境变量。不得将这些工具凭据复制到目标产品运行配置、前端、业务数据或测试清单，不打印 `.env`、认证头或完整响应。

## Prompt 只补缺，不强制扩写

检查四件事即可：

1. 图片的开发用途，以及具体主体与场景；
2. 目标容器比例、主体位置、文字留白和裁剪重点；
3. 必要的风格与主要色彩；
4. 不应出现的文字、品牌或其它元素。

已有描述足够时直接使用，只补影响当前结果的缺口，不追求字数，不机械添加镜头参数、复杂材质故事或多个创意方向，不为普通开发配图查阅案例库。页面标题、按钮和可维护数据由页面承载，不让背景图片生成这些内容。

只要求方向或 prompt 建议时不调用 API。已授权生成且目标明确时，执行固定脚本，不把保存 prompt 当成完成，也不在未执行命令时反复检查不存在的文件。

## 成本、错误与验收

- 一次命令只发起一次生成请求，关闭 SDK 自动重试，服务调用超时为 300 秒；失败不换模型、接口或来源，也不自动重抽。调用前独占目标文件，避免同一路径并发触发重复付费；执行中可能出现空占位文件，必须等待命令成功结束后再检查图片。
- 普通调用或写入失败时清理本次创建的未完成文件，不删除其它任务替换进去的文件。若进程被强制终止而留下占位文件，后续调用仍会拒绝覆盖；先核实原命令已结束及文件归属，再清理，不盲目再次调用。
- 退出码 `0` 表示已收到单张图片、检查 PNG 头与结束标记和请求尺寸，并保存了明确文件；stdout 为文件路径、模型、实际尺寸、MIME 与字节数的 JSON。它不等于图像完整解码或视觉验收通过。
- 退出码 `2` 表示输入、配置或输出路径预检失败，不会调用生成 API。退出码 `1` 表示真实接口、响应或文件保存失败。根据 stderr 的 HTTP 状态或错误类型处理，不回显可能包含秘密的原始服务错误正文。
- 401/403 检查现有凭据及权限；404 检查已配置端点和模型；400 检查实际参数兼容性；429 检查配额或限流。不要以换服务、重复发请求或另写脚本代替定位。
- 成功后必须实际打开图片，检查可读性、主体、畸变、异常文字、第三方权利与用途；用于页面时检查实际裁剪、文字对比和目标视口。生成图片不替代客户授权素材、真实商品照片或事实准确性要求。
- 满足开发用途就停止。只有存在具体、影响用途的缺陷且仍获授权时，才针对缺陷修正；禁止系统性批量填充数据库、Seed 或内容库。
