- 实验组加载本 Skill，并实际调用其要求的插件入口。
- 基线组仅实际调用 `ui-ux-pro-max:ui-ux-pro-max`，不读取本 Skill 的正文或参考；不能用完全不使用插件的结果冒充本次基线。

每例使用独立输出目录；精修例先分别复制原始夹具，不让两个执行者编辑同一文件。浏览器分别使用专属页面或命名 session，不能通过全局关闭清理。截图和运行结果放在根工作区 Git 忽略的 `.test-screenshots/frontend-ui-ux-workspace/`，不写回夹具或提交结果流水。

先检查真实调用接线：开发角色工具包含 Skill，执行记录中出现指定入口的实际调用及成功结果。角色定义或插件变更后使用新会话验证，旧会话可能缓存工具列表；不能以只读 Skill 正文代替。

对功能断言优先用实际浏览器行为或确定性检查，静态关键词不能证明调用、交互和导航吸顶。精修例使用短视口形成真实滚动，不靠保留无意义留白制造长页面。视觉比较采用一致视口与相近状态，盲评时隐藏实验组标签；评审围绕用户任务和设计约束，不追求固定分数。

保留调用、交互、渲染、耗时和真实缺口的相称证据。工具中断、API 重试和未覆盖范围单独说明，不将它们直接归因为 Skill 效果。单次样例通过不能证明普遍视觉提升或效率收益。

用创建工具提供的结果查看器展示原始输出与断言结果。Skill 维护时的对比评估不构成产品运行中的人工审批环节。
