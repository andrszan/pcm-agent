# 设计术语与 Prompt 表达库

用于把产品意图、参考效果或“精致、丝滑”等概括转为具体设计要求；在构思页面、精修组件或编写子 Agent 任务时按需查阅。本文件提供选词与话术，不替代插件建议、产品判断和真实预览。

## 怎样选词、怎样写

先从真实任务挑出需要表达的关系，再选能消除歧义的词。常用写法是：**意图 → 对象 → 可见特征或行为 → 验证片段**。已确定的设计保留什么、执行者能调整什么，写在当前任务中。

- 主 Agent 把所选条目改写为当前对象的要求。例如把“视觉层级”展开为“工单名称与待处理状态优先，时间与备注退后一层”，而不只转发术语或整份词典。
- 参考已确认时，传递参考位置、具体借鉴维度与保留关系；需要探索时，说明局部允许调整的范围。参数可由执行者结合内容与实际渲染校准，不为每个样式值增加审批。
- 视觉要求可围绕布局、字阶、颜色角色、密度、表面中的相关维度组织；不要求每次填全。已有组件的小修改可只有几句，完整页面才需要更充分的描述。
- 动效片段交代相关的触发、对象、起止状态、节奏、编排、中断或反向行为及替代状态。固定时长、曲线和弹簧参数按场景选，不把示例数值升为全站规范。
- 术语和片段是可选材料，不是每页必用清单。按任务决定表达强度；后台可以精细、有趣，展示页面也不必叠加所有效果。关键词数量不代表设计质量。
- 以下 Prompt 是可改写的例句，不是插件默认值；示例涉及的效果不预先授权安装依赖、复制素材或新增业务功能。

需要复现或比较明确节奏时，可给出可校准的起点。例如：“功能卡片首次进入视口，从下移 12px、透明度 0 过渡到原位与完全可见；约 280ms、ease-out，相邻卡片错开约 50ms，限制整组等待时间；减少动效时直接呈现。”这组数值只描述该入场例子，不移植为按钮、抽屉或所有页面的默认值。

## 容易混淆的表达

- **风格、布局、系统分开理解**：Bento 是布局模式，Glassmorphism 是视觉处理，Material Design 是覆盖组件、行为与视觉的设计系统。“苹果风”“Linear 风”需要进一步说明借鉴的属性。
- **概念图与真实界面分开描述**：8K、masterpiece、电影级光影等适合相关图像资产，不足以定义界面层级、响应式和操作状态。需要三维材质时说明它用于哪个资产。
- **名称不等于实现**：Aurora、Beams、Splash Cursor 等也可能是库内组件名。通行术语可帮助搜索，具体效果还应描述或附演示；不因为同名就引入该库。
- **静态参考的证据有限**：截图可以支持构图、配色、文字层级判断；手势、加载、中断、滚动与手机行为若未观察，应作为待设计内容而非已知事实。
- **Sheet 不等于 Form**：Bottom Sheet 是底部面板，Modal Sheet 是模态面板，可以承载表单，也可以承载其他内容。模态与非模态的焦点和背景交互行为不同。

## A. 布局与信息

| 术语与含义 | 适用与边界 | 可改写的 Prompt 片段 |
|---|---|---|
| Visual Hierarchy／视觉层级：建立阅读与操作主次 | 同时考虑位置、大小、对比、分组；不是全页加粗 | “对象名称与下一动作优先，辅助时间和备注退后一层，强调色用于主要操作。” |
| Information Density／信息密度：单位空间的信息量 | 扫描、比较、阅读各有需求；留白多不自动更好 | “保留比较所需的关键列，压缩重复装饰，行高仍支持触控与多行标题。” |
| Grid System／栅格系统：共同的对齐结构 | 随内容与屏幕变化，不强迫所有表面同栏数 | “标题、图片和操作区共享对齐线；窄屏重排后保持阅读顺序。” |
| Single-column／单列布局：一条主要阅读路径 | 适合连续阅读与简单流程；比较任务可能需并列 | “采用单列阅读结构，控制正文宽度，章节之间保持清晰节奏。” |
| Split-screen／分屏布局：两侧承担不同任务 | 桌面叙事与预览、登录与品牌；手机需确定顺序 | “左侧说明价值，右侧展示产品预览；手机先说明再预览。” |
| Bento Grid／便当盒布局：大小不同的模块组合 | 按重要性与内容关系分配面积，不随机拼卡片 | “核心能力占大块，辅助能力占小块，模块间距与几何规则一致。” |
| Card-based Layout／卡片式布局：独立对象成组 | 卡片须有清楚内容边界；不是所有段落都要套框 | “每张卡片表达一个项目，标题、状态和入口位置一致，方便比较。” |
| Masonry／瀑布流：不同高度内容按列排列 | 适合图片浏览；核对视觉与键盘阅读顺序 | “作品保留原始图片比例，按列紧密排列，窄屏自然收敛为单列。” |
| List–Detail／列表—详情：选择对象并查看内容 | 高频比较与连续处理；保留选择、筛选和返回位置 | “桌面采用列表与详情双栏；手机打开详情后可返回原列表位置。” |
| App Shell／应用框架：稳定导航与工作区域 | 沿用工程导航与滚动归属，不自行增加多层滚动 | “切换工作内容时主导航位置与选中关系稳定，关键入口在长页面中可达。” |
| Progressive Disclosure／渐进披露：按需呈现细节 | 常用项直接可见；重要规则与核心操作不能藏起来 | “常用筛选直接展示，低频条件在高级筛选中展开，保留已选内容。” |

## B. 风格与材质

| 术语与含义 | 适用与边界 | 可改写的 Prompt 片段 |
|---|---|---|
| Minimalism／极简主义：减少非必要元素 | 保留任务需要的内容、标签与状态 | “通过留白、字重和有限强调色建立层级，减少无信息价值的装饰。” |
| Swiss／International Typographic Style／瑞士风格 | 严谨栅格、无衬线字体、对齐与不对称平衡；不只是大黑字 | “以清晰栅格、左对齐标题与稳定字阶建立秩序，留白对应内容分组。” |
| Editorial Design／编辑式设计：杂志般图文节奏 | 适合内容叙事与案例；文字应提供真实信息 | “以标题、引言、大图和图注组织阅读节奏，相关图文靠近，章节间留白。” |
| Glassmorphism／玻璃拟态：半透明与背景模糊 | 适合需要前后层次的局部表面；核对背景变化和成本 | “悬浮导航使用半透明表面、背景模糊、细亮边和轻阴影，亮背景下仍可读。” |
| Skeuomorphism／拟物：借用真实物体形态与材质 | 真实隐喻应帮助理解操作，避免装饰掩盖状态 | “音量旋钮带清楚刻度与金属高光，转动与数值同步，键盘也能调整。” |
| Neumorphism／新拟态：同色表面呈现凹凸 | 适合局部质感；低对比控件需明确边界和焦点 | “同色表面用轻微亮暗阴影表达凹凸，选中和可操作状态仍清楚可辨。” |
| Brutalism／网页粗野主义：直接、原始的结构表达 | 风格范围较宽；应说明实际排版与材料 | “使用直接的大字排版、明显结构与少量装饰，保留可识别导航。” |
| Neo-brutalism／新粗野主义：粗边框、实色、硬阴影 | 适合有依据的个性品牌；不以强对比代替层级 | “采用黑色描边、明亮实色和无模糊偏移阴影，主次操作仍有明确权重。” |
| Claymorphism／黏土拟态：圆润柔软的三维质感 | 可用于插画或适合的组件；文字与控件需清楚 | “引导插画采用圆润黏土形态、柔和体积光，与现有品牌色协调。” |
| Retro-futurism／复古未来主义：历史想象中的未来 | 说明年代、媒介与范围；终端或扫描线只是可选方向 | “装饰区域借用复古终端的等宽字与轻扫描线，正文与输入保持现代可读性。” |

风格可组合，但组合应能解释。例如编辑式排版可以采用极简视觉；已有品牌精修不因词典提供新方向而重新选型。

<a id="detail"></a>
## C. 视觉细节

| 术语与含义 | 适用与边界 | 可改写的 Prompt 片段 |
|---|---|---|
| Type Scale／字号阶梯：稳定的文字等级 | 复用已有字阶，结合中文长度与窄屏断行 | “标题、正文、辅助信息有明确级差，同类模块使用同一层级。” |
| Typographic Contrast／字体对比：字形、字重、大小的区别 | 比较数字可用等宽数字；不是全部使用等宽字体 | “标题通过字重突出，正文保持常规重量，数值列采用等宽数字并对齐。” |
| Leading／Tracking／行距与字距 | 中文和英文节奏不同；不照搬大字距全大写风格 | “正文行距便于连续阅读，中文标题按真实换行校准，避免文字挤压。” |
| Negative Space／留白：内容周围的空间 | 用于分组与节奏；不为留白隐藏必要信息 | “相关字段靠近，组间间距大于组内，用空间减少多余分割线。” |
| Spacing Scale／间距尺度：复用间距档位 | 优先使用项目尺度，4／8 倍数只是常见起点 | “把卡片内距与字段间距映射到现有档位，统一同类组件的节奏。” |
| Semantic Colors／语义色：颜色承担稳定角色 | 状态不只靠颜色；品牌色不能混淆危险与成功 | “区分品牌强调、选中和错误角色，错误同时给出图标或文字说明。” |
| Elevation／层级高度：表面与阴影表示前后关系 | 并非必须给每张卡片加阴影 | “基础内容使用低层级表面，浮层通过适量阴影与背景遮罩表达上层关系。” |
| Hairline Border／细描边：轻量边界 | 太淡会失去识别；焦点需比普通边界明确 | “卡片用低对比细边界分组，在聚焦或选中时加强可辨识反馈。” |
| Design Token／设计令牌：颜色、尺寸等的语义引用 | 接入现有体系，不额外建立一份重复数值真源 | “使用现有 surface、border、accent 等语义角色表达表面与状态。” |

## D. 图形特效

| 术语与含义 | 适用与边界 | 可改写的 Prompt 片段 |
|---|---|---|
| Dot Grid／点阵网格：规则间距的点 | 画布底纹或局部氛围；不是用点表现图像明暗 | “背景使用低对比规则点阵，在主要正文附近淡出，不抢阅读层级。” |
| Dot Matrix／点阵显示：点组成文字或图像 | LED、像素风表达；标题仍需保留语义与清晰版本 | “装饰标题由点阵逐步构成，最终字形完整，减少动效时直接呈现。” |
| Halftone／半色调网点：网点大小或密度表现明暗 | 印刷视觉与图片处理；不是随机颗粒或普通点阵 | “作品图以半色调网点保留明暗与轮廓，正文不叠网点纹理。” |
| Particle Field／粒子场：散布粒子运动 | 局部氛围；控制密度、运动范围与设备成本 | “稀疏粒子缓慢漂移，正文保持安静，离开视口后暂停装饰运动。” |
| Flow Field／流场：粒子或曲线沿方向场运动 | 有连续方向趋势的流动；不是每根线独立乱摆 | “细线沿平滑噪声流场缓慢流动，维持整体方向与稀疏留白。” |
| Streamlines／流线：显示流动方向的曲线 | 静态流向或沿曲线移动的亮段；需说明是否运动 | “几条曲线上有细亮段从左下向右上移动，明确方向，限制亮度。” |
| Mesh Gradient／网格渐变：多色控制点柔和融合 | 大色块背景；颜色数量、位置和变化需适配品牌 | “用品牌色与邻近辅助色构成柔和多点渐变，标题区保持足够对比。” |
| Aurora／极光效果：柔软的发光色带 | 氛围表达或库内具体效果名；需看实际形态 | “顶部的低饱和色带缓慢弯曲漂移，光亮不穿过主要文字。” |
| Grain／Noise Texture／颗粒纹理 | 印刷或表面质感；静态颗粒与闪烁噪声需区分 | “渐变叠加轻微静态颗粒，保留干净文字与控件边缘。” |
| Metaballs／融合球：软形体靠近后连接 | 液态图形表达；形变不影响必要标签和操作范围 | “柔软圆形靠近后平滑融合，分开时连接收缩，循环范围局限于插画。” |
| Displacement／位移扭曲：图像被噪声或水波偏移 | 图片过渡或悬停反馈；提供完整、稳定图像状态 | “图片悬停时出现轻微局部水波位移，离开后平滑恢复，触控直接看原图。” |
| Iridescence／虹彩：类似干涉色的变化高光 | 珍珠、金属膜等材质表达；不是所有彩虹渐变 | “装饰物高光带有柔和虹彩，随视角轻微变化，整体色调服从品牌。” |
| Cursor Trail／光标拖尾：指针留下短暂轨迹 | 创意展示的可选细节；触控无指针时功能完整 | “指针留下短而快速衰减的轨迹，不遮挡链接，不替换必要点击反馈。” |
| Spotlight／聚光追踪：光斑跟随指针 | 局部表面层次；鼠标光斑不能替代键盘焦点 | “卡片内柔和光斑随指针移动，裁切在卡片内，键盘聚焦有独立标记。” |

用户说“流线”时，依据参考判断是静态曲线、沿路径运动的光束还是流场；不必为普通可逆选择反复追问，但在任务文本中写清所选解释。React Bits 等站点适合确认长相与组件名称，不能据名字推断已验证其性能或所有平台行为。

<a id="motion"></a>
## E. 动效编排

| 术语与含义 | 适用与边界 | 可改写的 Prompt 片段 |
|---|---|---|
| Easing／缓动：运动速度如何变化 | ease-out 常用于快速响应后减速；不是所有动作同一曲线 | “面板立即响应，进入末段柔和减速；退出按其空间关系选择节奏。” |
| Duration／时长：变化持续多久 | 按位移、范围、频率调整；示例毫秒不是规范 | “按钮反馈比大面板切换更短促，连续操作不等待上一段播放结束。” |
| Delay／延迟：触发到开始的等待 | 用于相关动作配合；不要延迟主要操作反馈 | “主要操作立即回应，辅助说明稍后出现，不推迟按钮可用时间。” |
| Stagger／交错动画：多元素错开开始 | 少量内容引导阅读；长列表与高频更新限制总等待 | “卡片按阅读顺序短暂错开淡入并上移，已显示内容可立即操作。” |
| Spring／弹簧：stiffness 刚度、damping 阻尼、mass 质量决定运动 | 可以低回弹或无过冲；库间参数不可直接混用 | “选中标记用低回弹弹簧跟随新位置，快速接近后稳定停住。” |
| Overshoot／过冲：超过目标后回落 | 适合有依据的局部强调；阅读与高频操作避免反复晃动 | “完成图标可有一次轻微过冲，确认后静止，其他内容不随之弹跳。” |
| Inertia／惯性：释放后保留速度并减速 | 已有拖动或滑动交互；不是授权新增手势 | “拖动释放后延续当前速度并减速，停在有效范围，不越出操作边界。” |
| Interruptibility／可中断性：新操作改变运动目标 | 快速反向与连续选择；兼顾视觉与业务状态一致 | “展开中途关闭时从当前位置返回，不先跳回起点或强制播完。” |
| Shared Element Transition／共享元素过渡 | 同一对象跨状态保持来源关系；需有实际对应元素 | “卡片封面与标题连续过渡到详情对应位置，返回时保持空间来源。” |
| Layout Animation／布局动画 | 重排时保持对象可追踪；不得扭曲文字或打断输入 | “筛选后保留项平滑移动到新位置，当前焦点和选择关系仍明确。” |
| FLIP／First、Last、Invert、Play | 实现布局动画的思路，不是独立视觉风格 | “重排保持连续，可用 FLIP 或现有能力实现，内容在过渡中仍清楚。” |
| Mask Reveal／遮罩揭示；Line Reveal／逐行揭示 | 文字或图片从裁切区显露；中文换行后重新检查 | “标题按行从遮罩内上移出现，保留完整语义；窄屏不裁掉字形。” |
| Scroll-triggered／滚动触发 | 到达位置开始播放；播放不必跟随滚动进度 | “章节首次进入视口时播放一次，向上滚动不会再次隐藏已读内容。” |
| Scroll-linked／Scrub／滚动绑定 | 滚动位置映射动画进度，可向上逆转 | “本章节滚动进度对应图片变化进度，向上滚动按同一轨迹回退。” |
| Pin／滚动期间固定 | 局部叙事；定义开始、结束与解除后的页面流 | “仅在该章节内固定演示区，说明滚完后恢复正常布局，手机顺序展示。” |
| Parallax／视差：不同层以不同速度运动 | 空间层次；小幅使用并提供减少动效版本 | “背景比前景移动缓慢，幅度保持轻微，减少动效时保持静态。” |
| Choreography／动效编排 | 多对象时序配合；主操作不为表演而等待 | “标题先出现，证据与配图随后呈现，主要按钮始终可见可用。” |
| Reduced Motion／减少动态效果 | 保留信息与必要反馈；不能只把内容停在隐藏起点 | “关闭视差、弹性与装饰循环，直接显示完整内容或使用短淡入。” |

用“快速接近目标、低回弹、连续切换不跳变”描述手感，通常比只写“丝滑”更有约束力。物理弹簧的结束时间与固定时长动画不同；选择当前技术栈支持的表达，细节在真实操作中校准。

<a id="interaction"></a>
## F. 组件与交互

| 术语与含义 | 适用与边界 | 可改写的 Prompt 片段 |
|---|---|---|
| Modal Dialog／模态对话框 | 背景不可交互、焦点在内部；关闭后的落点符合流程 | “打开后焦点进入对话框，支持 Escape 与关闭按钮；关闭后返回入口或下一合理位置。” |
| Drawer／抽屉；Bottom Sheet／底部面板 | 边缘出现的补充内容；是否模态另行确定 | “桌面从侧边打开筛选，手机使用底部面板；保留已选条件与清楚关闭方式。” |
| Popover／弹出浮层 | 与触发对象关联的内容；边缘空间不足需调整 | “日期浮层贴近输入框，空间不足时换边显示，不挡住当前输入。” |
| Tooltip／工具提示 | 短小辅助解释；必要规则与操作不能只放这里 | “图标悬停或聚焦时显示名称，重要说明直接保留在表单内。” |
| Toast／轻量通知 | 非阻断反馈；重要失败需要持久可查与恢复入口 | “保存成功后轻量提示，失败原因在相关区域保留并可重试。” |
| Command Palette／命令面板 | 适用于已有快捷操作需求；不为展示组件加功能 | “输入过滤命令，上下键选择、Enter 执行、Escape 关闭，焦点返回原位置。” |
| State Matrix／状态矩阵 | 列出当前组件实际相关状态，无须机械补全无关状态 | “区分默认、悬停、聚焦、按下、选中与忙碌；保存结果再区分成功和失败。” |
| Inline Validation／行内校验 | 错误贴近字段，反馈时机符合输入过程 | “提交时指出错误字段与原因并保留输入；修正后及时更新相关提示。” |
| Optimistic UI／乐观更新 | 可恢复的低风险操作；关键业务须按真实结果确认 | “收藏立即更新，保存失败时回退并提供重试，不能提前宣告交易完成。” |
| Skeleton Screen／骨架屏 | 真实数据等待时保持布局；不制造假等待 | “按内容结构占位，数据返回后原位替换，避免整块跳动。” |
| Empty State／空状态 | 初次无数据、筛选无结果的原因和下一步不同 | “首次无数据提供创建入口；筛选无结果显示清除筛选，不混为系统故障。” |
| Drag and Drop／拖放；Snap／吸附 | 已有排序或移动需求；提供非拖动操作途径 | “拖动时显示占位和可放置区，松手吸附到有效位置，同时支持按钮调整。” |
| Hover Intent／悬停意图 | 降低经过时误触发；触控与键盘有明确入口 | “指针停留后展开菜单，移入菜单时保持打开，点击与聚焦路径同样可用。” |
| Focus Management／焦点管理 | 键盘位置与页面状态同步；非模态抽屉不盲目困住焦点 | “内容切换时保持合理焦点，模态打开时移入并约束，关闭时恢复到原入口。” |

<a id="prompts"></a>
## 可组合的 Prompt 片段

以下是设计与交互部分，不是完整工程派工单。委派时仍使用[任务模板](../templates/subagent-task.md)补齐实际插件入口、资料位置、数据边界、文件归属和验证。只取适合当前任务的片段，替换业务对象；缺少的工程信息应按现场读取，不照示例虚构。

### 页面方向：编辑式内容首页

```text
为读者选择并阅读观察札记设计首页。以内容为主，采用编辑式排版：标题、真实摘要、配图和图注形成阅读节奏，分类与收藏作为辅助操作。
用共同对齐线和章节留白组织内容，相关图文靠近；不因页面有六篇文章就机械做六张等权卡片。字体、色彩和表面沿用已经选定的品牌方向。
手机按阅读顺序重排。用长标题、多行摘要和缺图状态检查节奏与可读性，保留阅读正文，删去重复介绍操作的文案。
```

### 组件精修：高频列表与详情

```text
只精修列表选择与现有详情面板，保持导航、品牌和业务流程。
对象名称与待处理状态优先，负责人和时间退后一层；选中行用现有品牌浅色面与明确标记表达，悬停和键盘焦点与选中状态可区分。
点击立即更新选择。详情首次展开用短促缓出，面板已打开时切换对象只更新内容，不反复播放整块入场。加载中保持结构，失败保留当前对象并提供重试；旧请求不能覆盖新的选择。
快速关闭或切换时从当前视觉状态继续；按现有模态或非模态语义管理焦点。窄屏返回后保留列表上下文，减少动效时完整呈现状态。允许校准局部间距、边界和过渡节奏，以连续切换、关闭、失败重试及键盘路径验证。
```

### 材质与背景：毛玻璃配点阵

```text
当前品牌方向需要有轻量科技感的顶部导航与首屏背景。导航局部使用半透明毛玻璃，通过细边界、轻阴影与背景模糊建立前后层次；正文和表单保持稳定表面。
背景采用低对比 Dot Grid，在主要文字附近淡出；若加入流线，明确为沿少量弧线路径移动的细亮段，不增加全页粒子与跟手效果。
检查亮暗背景下导航可读性、手机裁剪和实际渲染成本。不支持模糊时使用实色表面，减少动效时保留静态背景，菜单与焦点行为不受材质影响。
```

### 空间连续：卡片展开为详情

```text
在已有卡片打开详情的行为中，封面和标题作为共享元素连续过渡到详情对应位置，正文在主要位移接近完成时淡入。
采用低回弹弹簧，快速靠近目标后稳定。展开中途关闭时从当前位置返回，不先跳回起点或等待动画播完；连续选择时始终对应当前对象。
保留已有路由、关闭和焦点逻辑。减少动效时使用短淡入或直接切换；验证快速开关、长标题、图片未加载与手机布局，不拉伸文字、不裁掉主要操作。
```

### 滚动叙事：明确触发与进度绑定

```text
在已有三步产品介绍章节中，让演示随滚动呈现“输入、处理、结果”。滚动位置与变化进度绑定，向上滚动时沿同一进度回退，而不是进入视口后自行播完。
桌面可在本章节内固定演示区，说明各阶段的起止关系与解除固定后的页面流；阶段切换保留同一对象的空间联系，不接管整站滚轮。
手机和减少动效模式按三步顺序展示完整内容与结果。验证反向滚动、快速跨过章节、调整窗口和直接到达后续内容，核心信息不依赖动画播完才可见。
```

### 参考拆解：从“像这个网站”到具体要求

```text
先读取提供的参考与当前页面，区分实际观察和推测。提取与本任务有关的构图、字阶、颜色角色、密度与表面关系；若只提供截图，不把悬停、手势和手机行为描述为已观察事实。
说明借鉴哪些关系，并用当前产品的真实内容与流程重组。已有品牌不被参考站覆盖；尚未确定的局部细节由执行者选择并通过真实渲染校准。
把“更精致”转成具体对象上的改动和观察方式，例如卡片标题与元信息层级、按钮角色、图标对齐或切换连续性。对已成立的关系保持稳定，不为套风格新增功能。
```
