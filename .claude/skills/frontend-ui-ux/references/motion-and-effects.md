# 动效与特效

动效是操作与状态设计的一部分，不仅属于官网或宣传表面。后台和平台也应主动处理反馈、连续性和适量趣味；高频操作需要短促、稳定、不打断的表达，而不是一概取消动态。先确定当前关键动作与变化，再选择匹配的效果，不把整个项目当作特效展厅。

需要命名或写委派要求时，查阅[表达库的图形特效与动效编排](design-vocabulary-and-prompts.md#effects)，其中区分点阵、半色调、流场、遮罩揭示、交错、共享元素及滚动绑定，并提供可改写话术。选择与当前动作、品牌或信息关系相符的效果，控制范围、频率与背景对比；不为展示效果伪造等待。

## 先设计交互过程

从当前真实任务选择关键片段：按钮按下后的确认感、分段选择的活动状态、列表更新时对象关系的保持、详情展开和返回的空间连续、提交中的忙碌状态到结果的过渡。先让操作立即有响应，再表达业务结果；结果未知时保留核对路径，不能用完成动画提前宣告成功。没有对应业务的拖拽、翻转或手势不为趣味额外添加。

反馈可以细腻而有个性，例如状态图标的轻量形变、完成操作后局部的短暂强调、与内容相符的空态图形或选中标记过渡。可探索局部弹性、层次和材质变化，保持节奏与产品气质一致；连续处理任务时不逐条弹庆祝、不夺取焦点或延迟下一次操作。触控和键盘必须取得同等必要反馈，不让悬停成为唯一发现途径。

共享同类动作的时长与缓动关系，按位移、范围和频率调整，不全站套同一个 transition 或对所有属性过渡。列表和面板变化避免突兀跳动，但不强行给每个页面加进场表演。使用者请求减少动效时，去掉位移、弹性和装饰循环，保留可理解的静态状态及必要反馈。

将关键片段写成“触发 → 对象与起止状态 → 节奏与编排 → 中断或反向 → 替代状态”，按当前任务补足相关部分即可。区分首次展开与已展开后的内容更新；连续操作应从当前视觉状态转向新目标，不强制播放完旧动画。滚动触发是到达位置后播放，滚动绑定是进度随滚动变化；需要反向时明确映射，固定章节还需说明解除位置与窄屏替代。具体术语、参数含义与例句以表达库为准，不在此重复维护词典。

## 实现与复验

技术实现优先复用现有能力。简单表达用 CSS 或现有组件即可，不为单个效果引入新的大型动效、3D 或视频体系。`transform`、`opacity` 等通常更容易控制成本；模糊、大范围重绘和常驻粒子需实际观察。

确定静态回退、减少动效处理、窄屏裁剪及失败表现。内容与核心操作不依赖动画结束后才可用；运行暂停或动效关闭时仍有完整界面。不要全页循环运动、无差别入场、抢眼游标或跟手效果影响连续工作。

验证真实运行的遮挡、滚动、响应式、性能异常及减少动效模式；只截图一个漂亮帧不能证明行为正确。效果未改善任务或视觉表达时删掉，不用特效数量或模型评分证明精修成功。
