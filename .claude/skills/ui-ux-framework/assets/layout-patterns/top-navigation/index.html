内容分组

每个分组只解决一个阅读问题。标题说明主题，正文说明依据和影响，相关链接只作为补充，不抢占主要阅读路径。

当主题规模变大时，可以重新判断是否需要更深的局部导航；在此之前，保持简单的文档流更容易理解。

状态表达

状态用于帮助判断下一步，而不是制造视觉噪声。待确认、进行中和已完成应在内容本身附近给出可以理解的原因。

这种安排让用户阅读较长页面时仍能辨别哪些信息会影响当前工作。

维护节奏

内容不需要为每次小更新重组页面。优先更新最可能影响判断的段落，并定期归档不再适用的说明。

页面长度本身不是问题；无层次、无恢复线索的长度才是问题。
