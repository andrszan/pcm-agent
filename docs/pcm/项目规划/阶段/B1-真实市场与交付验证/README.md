## W01 市场与需求验证

**定稿方案**

从真实咨询、付款和交付中判断哪些全新 Web 定制需求有人买、哪些订单值得接、哪里需要调整，不另做一轮大规模市场调研。自有产品只作为能力案例，不形成销售订单。

**要验证什么**

- 咨询中反复出现哪些产品需求和功能；
- 客户是否实际支付 800 元、1000 元或 1200 元，不只看口头认可；
- 客户是否接受源码、Git 历史、文档及本地运行交付；
- React 和 Python 能覆盖哪些实际需求，哪些需求因指定技术而流失；
- 已成交需求的实际成本和人工投入是否可接受。

**记录与复盘**

- 复用 W06 渠道记录和 W07 咨询、订单记录，不另建调查表；保留咨询来源及对应内容或产品、主要功能、指定技术和第三方依赖、价格与本地交付接受情况、B1 承接判断、报价付款成交情况，以及已知的未成交原因；
- 从正常沟通获得信息，不额外调查身份、职业或购买用途；不清楚的记为未知，不把报价后未回复直接解释为嫌贵，也不反复追问；同一笔需求的多次聊天不重复计为独立咨询；
- 区分我们主动不接、客户明确不接受、暂时没有结果三种情况；范围或能力不匹配不直接算成客户不认可产品，不能硬填未成交原因；

## W03 价格与报价

**定稿结论**

- B1 只接难度较低、预计不会亏损的订单，项目总价统一使用 800 元、1000 元或 1200 元三档；
- 800 元用于内容较少、流程简单的项目，1000 元用于普通小型完整项目，1200 元用于内容相对较多或包含常见第三方服务接入的项目；
- 预计 1200 元仍不能覆盖成本，或者开发难度超出当前能力范围时，B1 直接不接；
- 定制开发价格已经包含最终业务成果的独家买断，不单独收取买断费用；
- 第三方服务接入代码及开发和验收期间的必要资源使用包含在项目报价中；交付后由客户按照交付文档自行获取并承担第三方账号、授权和资源费用；
- B1 不提供现有产品销售或购后修改、客户数据处理和迁移、客户生产环境部署、长期托管、持续维护或额外环境调试，因此不为这些项目报价；后续是否扩展服务根据商业化情况决定；
- 原范围真实缺陷按交付责任纠正，不借新增收费；新增或改变需求不包含在原报价中。

**透明报价**

每份报价按实际工作列出金额，但总价只使用当前三个档位：

```text
需求和项目设计：       ___ 元
页面与交互开发：       ___ 元
业务功能与数据开发：   ___ 元
第三方服务接入开发：   ___ 元
测试、源码和文档交付： ___ 元
项目总价：             800 / 1000 / 1200 元
```

同时写清楚包含功能、不包含内容、交付方式和预计周期。涉及第三方服务时，注明开发和验收期间的必要资源使用已经包含，交付后由客户按照文档自行获取相关账号、授权和资源。报价不展示内部 Agent、模型成本和生产方法。

- 未按文档操作时先指向对应说明，不默认提供从零教学、整机排查或远程代操作；如果文档确有遗漏、错误或容易误解，应修正文档；

## W13 成本、财务与产能

**定稿方案**

只用一个表格的订单记录、公共开支两个页，不开发财务系统。回答每单收支、人工时间和真实产能三个问题。

- 订单沿用 W07 编号，记录服务类型、报价、首尾款与退款、已结算到账与平台待结算金额、直接费用、公共分摊和相关税费、各环节工时及开工、首版、交付和关闭日期；
- 模型订阅、官网域名与托管及实际发生的公共工具、宣传和经营费用按月汇总，先按当月订单数简单均摊；明显专属于某单的直接归属该单，不重复计算；一次性启动和正式 PCM 研发投入另列，在阶段复盘时一起看；
- 按量模型账单与订阅费分开，理论 Token 价格不当成实际扣款；开发和验收期间的第三方资源计入订单成本，交付后客户自行购买的资源不计入我们的支出；
- 收款手续费单列，不在净到账金额之外重复扣除；退款、返工、交付后问题处理都记录，实际账单与估算值、客户付款与平台结算到账分清；
- 人工只粗记需求沟通、开发介入、测试交付、后续问题处理四类工时，不逐分钟计时；Agent 自行运行的等待时间不直接算人工，实际盯守和处理时间才算；
- 同时查看扣除费用后的结余和个人工时，未给自己的时间设参考时薪时注明未扣个人工时成本，不称净利润；内部经营记录不替代税务账务和申报。

**复核与产能**

- 报价前估算能否承接，交付后初步复核，订单关闭后及发生后续问题时补齐相关工时、费用、退款和最终结果；成本超支不事后单方面加价，用于下一单的范围、档位和接单判断；
- B1 只统计全新定制订单；自有案例不形成销售收益，不能用其它收入掩盖定制亏损；
- 首单验证期间只承诺一个正式开发中的定制订单，取得机器占用、人工介入和验收数据后再尝试两个并行订单；不限制生产系统本身的并发能力，排期要为咨询、验收和后续问题处理留出空间；
- 是否增加并发，以首版周期稳定、人工可控、项目互不干扰且能履行交付责任为依据，不以机器能启动多少任务代替实际交付能力。

**完成情况**

- [x] 确定记录字段、费用归属和简单分摊方式；
- [x] 确定复核节点和首单产能安排；
