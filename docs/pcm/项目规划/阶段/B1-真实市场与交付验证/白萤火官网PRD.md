# 白萤火官网 PRD

版本：v1.3 · 日期：2026-09-15 · 交付范围：面向国内的中文响应式单页官网、本地预览与静态构建。

## 1. 目标与内容原则

白萤火提供小型 Web 软件定制开发。本次官网面向国内访客，使用“白萤火”中文品牌标识，宣传内容和交互文案采用简体中文。官网帮助访客迅速理解服务、看到真实作品，并通过微信二维码发起咨询。

内容精简、抓住宣传重点；UI 的审美与完成度是另一项核心要求。用清楚的标题、短文案和真实界面建立信任，让访客轻松浏览。

页面内容按第 2 节组织；第 3～6 节用于指导设计、工程实施与验收。

## 2. 页面内容

全页包含首屏、服务亮点、自有案例、联系区四个部分。顶部展示品牌、案例与联系的页内导航，以及主题切换入口；页脚保留品牌名和回到顶部入口。

### 2.1 品牌首屏

默认文案：

> 白萤火
>
> 把你的需求，做成可以运行的软件。
>
> 小型 Web 软件定制开发。按需求设计，交付源码与运行文档。

主按钮“咨询定制”进入联系区，次按钮“查看案例”进入案例区。

首屏用文字标识、充足留白与真实产品界面建立第一印象。电脑端可用文字与截图相互平衡的构图，手机端按标题、简述、操作和截图依次排列。

### 2.2 服务亮点与参考价格

用三个简短亮点介绍服务：

- **按需定制**：围绕你的业务流程设计与开发。
- **现代技术**：采用 React + Python，覆盖展示网站、管理后台和轻量业务工具。
- **源码交付**：交付应用源码与运行文档。

价格作为服务区内一条醒目的简短信息：

> 定制参考价 800～1200 元，根据具体需求、工作量和实际成本预估，在区间内确定报价。

### 2.3 自有案例

**食序 MealFlow**

> 把家庭库存、每周菜单和共享采购连接起来的饮食协作工具。

用“库存与临期提醒”“菜谱与周菜单”“共享采购”三个短标签辅助说明。展示今日概览和菜谱详情两张真实截图，让界面本身体现开发能力。

案例区以大图为主，文字为辅。支持点击放大查看图片，查看层提供清楚的关闭入口与键盘操作；关闭后焦点回到原入口。后续案例沿用同一展示结构补充。

### 2.4 微信联系区

标题：**聊聊你想做的软件。**

辅助文案：**添加白萤火微信，告诉我们你的想法。**

展示完整加好友二维码与昵称“白萤火”。二维码使用提供的原图并保留留白，电脑与手机端均可清楚查看；保留图片的原生长按操作，便于手机访客保存后在微信中识别。

## 3. 视觉与交互

### 品牌与构图

整体方向为温和、克制的微光风格：以中性黑白建立清楚、专业的阅读体验，用少量偏黄的萤火绿形成品牌识别。

- 使用“白萤火”文字标识，可搭配一个简洁的微光图形。
- 亮色清爽、舒展；暗色安静、有层次。真实案例截图是主要视觉内容，两种主题均保留原图色彩。
- 用标题字阶、留白、图片比例和版面节奏建立层级。服务亮点采用轻量排版，案例用大图展示，价格保持简洁醒目。
- 品牌微光集中在标识或首屏局部，正文和内容区域以清晰阅读为主。
- 电脑端控制阅读宽度；手机端自然重排，保持舒适的字号、间距和触控区域。二维码和截图按原比例完整展示。

### 亮暗主题

支持“跟随系统／亮色／暗色”，首次跟随系统，并记住用户手动选择。亮暗主题共用品牌色相，分别调整明度和层次。

以下为起始色值，开发时根据真实界面的对比度、图片搭配和交互状态统一微调：

| 用途 | 亮色 | 暗色 |
| --- | --- | --- |
| 页面背景 | `#F7F8F4` | `#141713` |
| 内容表面 | `#FFFFFF` | `#1D221B` |
| 主要文字 | `#20261C` | `#EEF2E7` |
| 次要文字 | `#626B59` | `#A6AF9B` |
| 品牌强调 | `#526B25` | `#C4DE83` |
| 柔和强调背景 | `#EAF0DC` | `#29331E` |

亮色主题主按钮采用深苔绿底、白字；暗色采用萤火黄绿底、深色字。边界、悬停、选中和键盘焦点随主题保持清楚，状态提示结合文字或图标表达。

### 交互反馈

- 导航与咨询按钮准确进入对应页内区域，品牌点击回到顶部。
- 按钮悬停、图片查看和主题切换提供轻量反馈；一般颜色与状态过渡约 150～200 毫秒。
- 主题在页面首次绘制时正确应用，切换过程平稳。
- 遵循 `prefers-reduced-motion`，减少动态偏好下采用即时切换或静态反馈。
- 键盘焦点清楚可见，导航、主题切换和图片查看均可通过键盘操作。

## 5. 工程交付

- 在独立官网工程中使用 React 实现静态单页，沿用目标工作区运行与端口约定。
- 品牌文案、参考价格、案例资料、图片引用和主题色集中维护，便于后续调整。
- 页面内容取自第 2 节，公开资源采用第 4 节素材；构建产物检查覆盖公开内容和资源清单。
- 配置页面标题、简介和图片替代文本。
- 交付官网源码、静态资产、依赖与构建配置，以及简洁的本地运行、构建和内容修改说明。
