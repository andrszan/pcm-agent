# 菠萝灯官网 PRD

版本：v1.0 · 日期：2026-09-07 · 交付范围：可本地预览、可静态构建的官网首版。

本文和同目录 `assets/` 中的四张图片构成完整开发输入，不需要依赖此前的讨论记录。品牌、业务范围、首批案例和咨询方式已经确认；本文件不是食序或尾屿的改造需求。

## 1. 产品目标

菠萝灯提供全新 Web 软件定制开发。官网让访客快速了解能做什么、报价范围、如何交付，并通过独立业务微信发起咨询。

首版只做一个响应式展示官网，不是软件商城，也不是客户业务后台。

- 当前品牌使用“菠萝灯”，名称已由负责人暂定；不重新命名或展开商标检索。后续如需更名，集中修改品牌文案和素材即可。
- 面向有范围明确的 Web 开发需求、能够按照文档在自己电脑上准备环境并运行项目的客户；不调查与交付无关的身份和购买用途。
- 食序 MealFlow、尾屿 tailisle 是负责人指定的自有展示案例，仅展示能力，不出售。
- 以真实功能、清楚报价和明确交付建立信任，不虚构客户数、成交数、评价、团队规模或合作品牌。

## 2. 范围

### 必须有

- 单页首页：品牌首屏、定制服务、报价说明、开发与交付流程、自有案例、常见问题、微信联系区。
- 电脑和手机布局、页内导航、有效的咨询入口。
- 两个案例的真实截图、介绍和功能重点。
- 业务微信号展示、复制微信号、完整加好友二维码。
- 本地预览、静态构建产物和必要运行说明。

### 当前不做

- 用户注册登录、客户门户、订单中心、在线支付、购物车或内容管理后台。
- 咨询表单、客户资料数据库、自动需求生成、自动报价或在线客服系统。
- 案例产品售卖、单品价格、咨询购买、现有产品换皮和购后修改入口。
- 公开的案例产品登录或在线试用入口；不嵌入它们的本地服务。
- 免费维护套餐、固定免费修复期、固定售后响应承诺、工单或自动修复系统。
- 本地首版不要求完整 VI、产品视频、付费字体或额外媒体服务。

### 3.2 定制开发服务

只介绍一种主营服务：按确认需求新开发 Web 项目。

- 可以按约定提供纯前端、Python 后端或完整前后端项目。
- 当前主推 React + Python；其它技术栈后续逐步提供，不提前承诺。
- 典型能力包括展示网站、管理后台、业务流程、用户权限、数据查询与看板、文件处理和常见第三方接口接入。
- 不套用现成业务模板，不做简单换皮；业务流程、数据结构、页面内容按需求形成。可以使用成熟基础工程和通用组件，不宣称每一行代码都从零手写。
- 当前不承接超出稳定能力、难度或成本范围的需求，也不把 App、小程序、游戏、大规模即时通信等列为标准服务。

服务介绍和案例展示分开，不将食序、尾屿包装成待出售的服务套餐。

### 3.4 开发与交付流程

用简短步骤说明：确认需求与范围、确认报价及协议、付款后开发、展示与功能验收、交付源码和文档、客户本地运行确认及结算。

- 约 7 天提交首版，从需求、材料和必要开发条件齐备、按约收到首款后起算，实际日期以订单确认为准。
- 付款方式暂定 30% 预付款、70% 尾款，具体节点按双方确认的协议执行。不称为定金，不添加未确认的退款或罚则。
- 客户定制项目交付约定的应用源码、对应 Git 历史、环境准备和运行文档、必要初始化与账号说明；包含前后端的项目分别交付对应仓库历史，不向纯前端订单额外承诺后端。
- 可以通过本地运行展示或视频确认功能；最终仍需客户按文档在自己的电脑上成功运行，不能把发出文件或收到尾款当成全部交付完成。
- 当前为一次性交付，功能确认、资料交接、本地运行和结算完成后正常结案，不设置额外售后等待期。

不要将这段做成在线订单操作流程，页面只负责介绍和引导咨询。

### 3.6 常见问题

用简洁问答呈现，不复制整份商业协议。至少覆盖：

- **能买食序或尾屿吗？** 当前只作为自有案例展示，不出售；可以咨询全新定制开发。
- **支持什么技术？** 当前主推 React + Python，其它技术栈按后续能力逐步提供。
- **多久交付？** 条件齐备后约 7 天提交首版，具体范围、日期和最终交付按订单确认。
- **交付什么？** 约定的应用源码、对应 Git 历史和必要的本地运行、初始化文档；包含前后端时分别交付。
- **是否部署上线？** 当前不提供客户生产环境部署、长期托管或持续维护。
- **需要懂程序吗？** 需要基本的电脑及开发环境操作能力，能够按文档准备环境并运行项目；不提供从零编程教学或逐行代码讲解。
- **第三方资源谁负责？** 开发验收期间必要使用已包含；交付后客户按文档自行获取并配置。
- **交付后有问题怎么办？** 使用下方已确认口径，不写固定免费修复期限或即时响应承诺。

问题处理文案：

> 本服务为一次性开发与源码交付，不包含持续维护、功能升级或额外环境调试。交付后如发现与订单约定不符的问题，可通过原订单渠道反馈，核实后按订单约定处理。
