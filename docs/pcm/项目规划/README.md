# PCM 项目规划

> 本文件夹是 PCM 项目长期规划和当前行动的独立阅读入口。
> 当前版本：2026-09-04
>
> 文件夹内的三份文档共同构成一套完整规划，不依赖其它文档才能理解。阅读顺序是：先看总纲，再看阶段规划，最后看当前章程。

## 阅读顺序

1. [项目发展总纲](./项目发展总纲.md)
   - PCM 要做什么；
   - `pcm-demo`、正式 PCM、商业平台和客户项目是什么关系；
   - 长期按照什么原则发展。
2. [阶段规划与讨论说明](./阶段规划与讨论说明.md)
   - 现在做到哪里；
   - 当前商业阶段要验证什么；
   - 接下来有哪些工作，应该按什么顺序讨论。
3. [当前商业阶段章程](./当前商业阶段章程.md)
   - 当前具体怎么接需求、报价、交付和复盘；
   - 当前提供什么、不提供什么；
   - 当前的价格假设和交付规则。

## 这套规划解决什么问题

它不是代码开发说明，也不是客户宣传材料，而是 PCM 项目整体工作的行动地图。这里的“工作”包括市场、宣传、接单、报价、交付、成本、运维、正式 PCM、商业平台和技术验证等内容。

规划采用“先看全局，再确定当前阶段，再逐项细化”的方式：当前阶段写详细内容，后面的阶段只写大方向和进入条件，等真正进入时再继续拆分。

## 维护规则

- 这三份文档自成体系，不把其它仓库文档当作阅读前提；
- 项目内部技术资料只作为后续具体工作时的补充，不改变这里已经确定的商业规划；
- 一件事只在一份文档中完整说明，避免重复和互相冲突；
- 发生新决定、新订单或新证据时，更新对应文档；
- 普通聊天没有形成新决定时，不额外建立会议纪要；
- 当前阶段结束后，保留阶段结论，再把下一阶段提升为新的当前规划。
